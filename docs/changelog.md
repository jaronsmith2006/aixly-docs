## October 2026

**Live chat**

- Real-time live chat: messages, typing indicators and team joins appear instantly
- See what a shopper is typing before they send it
- Previews of your latest messages above the chat button when the shopper has closed the chat
- Missed replies are emailed to shoppers with a **Continue the chat** link
- Sound and in-app alerts on any page, plus email/Slack reminders when a shopper waits 3 minutes
- Photos and PDFs in both directions (JPG, PNG, WebP, PDF up to 5 MB)
- Live chat satisfaction ratings

**Inbox**

- **Suggest reply**: an AI draft of your reply that you edit before sending
- Saved replies with the `/` shortcut and `{first_name}`
- Tags and a tag filter
- Orders placed after chatting shown on the conversation

**Smarter assistant**

- Saved answers and **Correct this answer** apply from the very next message
- **Teach the assistant**: answers your team gives in live chats are suggested for your knowledge base
- Returns filed directly in Shopify from the chat

**Sales**

- **Aixly impact** on the Dashboard, with stricter attribution (only shoppers who actually used the chat)
- Cart reminder with an optional discount code

**Storefront**

- **Embedded chat window**: a theme block that puts the chat inside any page section
- Open the chat from your own buttons (`data-aixly-open`) or JavaScript events (`aixly:open`)
- Shoppers always see that they're chatting with an AI assistant

**Dashboard and support**

- "Where shoppers find the chat" overview with copyable links and code
- Chat activity (visitors, chats, AI replies) with trends vs the previous period, and recent chats with automatic tags
- New **Support** page with privacy and EU compliance guidance

**Widget and admin**

- Icon size control and custom launcher icons
- The Appearance preview shows the real widget, including the chat button
- Mobile: full-screen chat without page scrolling behind it
- Simpler installation using Shopify's standard flow (no extra redirects)
