## Where to find it

- In the app, open **Appearance → Popups**

The preview shows the popup you're editing.

---

## Popup types

- **Greeting on load**: a friendly prompt shortly after the page loads
- **Idle popup**: a prompt when the shopper hasn't interacted for a while
- **Promotion popup**: an offer or announcement

Popups never cover new messages from your team: message previews always take priority.

Best practice: keep popups short and helpful, and don't overdo promotions.

---

## Proactive prompt

Invite shoppers to chat after they've been browsing for a while:

- Enable **Proactive prompt**
- Set **Show after (seconds)** (recommended: 20–40)
- Optionally show it only once per session

---

## Cart reminder

Recover carts with a gentle reminder, optionally with a discount code.

When it shows:

- The shopper has items in their cart, **and**
- they stay on the cart page for the time you set, **or** (on desktop) move to leave your store

Settings:

- **Remind shoppers about their cart**: turn it on
- **Message**: your text. Use `{code}` to include the discount code.
- **Discount code (optional)**: an existing code from **Shopify → Discounts**. Shoppers apply it with one **Apply code** click (it's added to their cart through Shopify's own discount link).
- **On the cart page after (seconds)**: 10–300
- **Show again after (days)**: 1–30

The reminder never appears while the chat is open or during a live chat. Orders placed after a shopper uses the reminder count toward **Aixly impact** on your dashboard.

:::tip
Create a dedicated code for the reminder (for example `CART10`) so you can see in Shopify how often it's used.
:::
